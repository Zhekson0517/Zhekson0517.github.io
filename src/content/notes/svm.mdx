## Introduction

Support Vector Machines (SVMs) find the optimal separating hyperplane by maximizing the margin between classes. The elegant mathematical formulation, the kernel trick for nonlinear boundaries, and strong theoretical guarantees make SVMs one of the most important algorithms in machine learning.

## Maximum Margin Classifier

For linearly separable data, the margin is the distance from the hyperplane to the nearest data point. The maximum margin hyperplane solves:

$$\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1, \quad i = 1, \ldots, N$$

The margin width is $\frac{2}{\|\mathbf{w}\|}$, so minimizing $\|\mathbf{w}\|^2$ maximizes the margin.

## Dual Formulation

Introducing Lagrange multipliers $\alpha_i \geq 0$, the dual problem is:

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^{N} \alpha_i - \frac{1}{2}\sum_{i=1}^{N}\sum_{j=1}^{N} \alpha_i \alpha_j y_i y_j \mathbf{x}_i^\top \mathbf{x}_j$$

$$\text{s.t.} \quad \alpha_i \geq 0, \quad \sum_{i=1}^{N} \alpha_i y_i = 0$$

The solution depends only on **support vectors** — points with $\alpha_i > 0$ that lie on the margin. The classifier is:

$$f(\mathbf{x}) = \sum_{i=1}^{N} \alpha_i y_i \mathbf{x}_i^\top \mathbf{x} + b$$

## Soft Margin SVM

For non-separable data, slack variables $\xi_i \geq 0$ allow margin violations:

$$\min_{\mathbf{w}, b, \boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^{N}\xi_i$$

$$\text{s.t.} \quad y_i(\mathbf{w}^\top \mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

The parameter $C > 0$ controls the tradeoff between margin width and classification errors. The dual becomes:

$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^{N} \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j \mathbf{x}_i^\top \mathbf{x}_j$$

$$\text{s.t.} \quad 0 \leq \alpha_i \leq C, \quad \sum_{i} \alpha_i y_i = 0$$

## The Kernel Trick

The key insight: the dual only involves inner products $\mathbf{x}_i^\top \mathbf{x}_j$. Replace with a kernel $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^\top \phi(\mathbf{x}_j)$ to implicitly map data to a high-dimensional feature space.

Common kernels:
- **Linear**: $K(\mathbf{x}, \mathbf{z}) = \mathbf{x}^\top \mathbf{z}$
- **Polynomial**: $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^\top \mathbf{z} + c)^d$
- **RBF (Gaussian)**: $K(\mathbf{x}, \mathbf{z}) = \exp\left(-\frac{\|\mathbf{x} - \mathbf{z}\|^2}{2\sigma^2}\right)$

The RBF kernel corresponds to an infinite-dimensional feature space.

## Python Implementation

```python
import numpy as np
from sklearn.svm import SVC
from sklearn.datasets import make_moons, make_classification
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.metrics import accuracy_score, classification_report
from sklearn.preprocessing import StandardScaler

# Generate nonlinear data
X, y = make_moons(n_samples=300, noise=0.2, random_state=42)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# Scale features (important for SVM)
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)
X_test_s = scaler.transform(X_test)

# Compare kernels
kernels = {
    'Linear': SVC(kernel='linear', C=1.0),
    'Polynomial': SVC(kernel='poly', degree=3, C=1.0),
    'RBF': SVC(kernel='rbf', C=1.0, gamma='scale'),
}

for name, model in kernels.items():
    model.fit(X_train_s, y_train)
    acc = accuracy_score(y_test, model.predict(X_test_s))
    n_sv = model.n_support_.sum()
    print(f"{name}: accuracy={acc:.4f}, support_vectors={n_sv}")

# Hyperparameter tuning with GridSearchCV
param_grid = {
    'C': [0.1, 1, 10, 100],
    'gamma': ['scale', 0.01, 0.1, 1],
}
grid = GridSearchCV(SVC(kernel='rbf'), param_grid, cv=5)
grid.fit(X_train_s, y_train)
print(f"Best params: {grid.best_params_}")
print(f"Best CV score: {grid.best_score_:.4f}")
print(f"Test accuracy: {accuracy_score(y_test, grid.predict(X_test_s)):.4f}")
```

## VC Dimension and Generalization

The VC dimension of a hyperplane in $\mathbb{R}^d$ is $d + 1$. However, the **effective** VC dimension of an SVM depends on the margin:

$$h \leq \min\left(\frac{R^2}{\gamma^2}, d\right) + 1$$

where $R$ is the radius of the smallest sphere containing the data and $\gamma$ is the margin. This bound is data-dependent and explains SVMs' good generalization even in high dimensions.

## Summary

- SVMs find the maximum margin hyperplane via convex optimization
- The dual formulation enables the kernel trick for nonlinear classification
- Soft margin SVM handles non-separable data via slack variables
- The RBF kernel maps to infinite-dimensional space implicitly
- Generalization is controlled by the margin, not the feature space dimensionality
