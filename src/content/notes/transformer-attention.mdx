## 引言

Transformer 架构由 Vaswani 等人在 2017 年的论文《Attention Is All You Need》中提出，彻底改变了自然语言处理领域的研究范式。与循环神经网络不同，Transformer 完全基于注意力机制，摒弃了递归结构，实现了高度并行化的序列建模。

## 自注意力机制

自注意力（Self-Attention）是 Transformer 的核心组件。给定输入序列 $\mathbf{X} \in \mathbb{R}^{n \times d}$，通过线性变换得到查询、键、值矩阵：

$$
\mathbf{Q} = \mathbf{X}\mathbf{W}^Q, \quad \mathbf{K} = \mathbf{X}\mathbf{W}^K, \quad \mathbf{V} = \mathbf{X}\mathbf{W}^V
$$

其中 $\mathbf{W}^Q, \mathbf{W}^K \in \mathbb{R}^{d \times d_k}$，$\mathbf{W}^V \in \mathbb{R}^{d \times d_v}$。缩放点积注意力计算为：

$$
\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}
$$

除以 $\sqrt{d_k}$ 的目的是防止点积值过大导致 softmax 梯度消失。当 $d_k$ 较大时，点积的方差也会增大，缩放因子将方差归一化。

## 多头注意力

多头注意力（Multi-Head Attention）将注意力空间分解为多个子空间，允许模型同时关注不同位置的不同表示子空间：

$$
\text{MultiHead}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\mathbf{W}^O
$$

其中每个头 $\text{head}_i = \text{Attention}(\mathbf{Q}\mathbf{W}_i^Q, \mathbf{K}\mathbf{W}_i^K, \mathbf{V}\mathbf{W}_i^V)$，参数矩阵 $\mathbf{W}_i^Q \in \mathbb{R}^{d \times d_k}$，$\mathbf{W}_i^K \in \mathbb{R}^{d \times d_k}$，$\mathbf{W}_i^V \in \mathbb{R}^{d \times d_v}$，$\mathbf{W}^O \in \mathbb{R}^{hd_v \times d}$。

通常取 $d_k = d_v = d / h$，这样多头计算的总代价与单头全维度注意力相当。

## 位置编码

由于 Transformer 不含递归或卷积结构，需要显式注入位置信息。正弦位置编码定义为：

$$
PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

这种编码具有一个重要性质：对于任意固定偏移量 $k$，$PE_{pos+k}$ 可以表示为 $PE_{pos}$ 的线性函数，使得模型能够学习到相对位置关系。

## 编码器-解码器结构

完整的 Transformer 由编码器和解码器堆叠而成：

- **编码器**：$N$ 层，每层包含多头自注意力和前馈网络，均使用残差连接和层归一化
- **解码器**：$N$ 层，在编码器基础上增加交叉注意力层，并对自注意力施加因果掩码

前馈网络（FFN）为：

$$
\text{FFN}(\mathbf{x}) = \max(0, \mathbf{x}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2
$$

内层维度通常为 $d_{ff} = 4d$。

## 注意力变体

### 稀疏注意力

标准自注意力的计算复杂度为 $O(n^2)$，对长序列不友好。稀疏注意力通过限制每个位置只关注部分位置来降低复杂度：

- **局部注意力**：每个 token 只关注窗口内的邻居
- **跨步注意力**：每隔 $l$ 个位置关注一次
- **组合模式**：结合局部与全局注意力模式

### 线性注意力

将 softmax 核函数化，利用结合律改变计算顺序：

$$
\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \frac{\phi(\mathbf{Q})(\phi(\mathbf{K})^\top \mathbf{V})}{\phi(\mathbf{Q})(\phi(\mathbf{K})^\top \mathbf{1})}
$$

当 $\phi(\mathbf{K})^\top \mathbf{V}$ 可预计算时，复杂度降为 $O(nd^2)$。

## Python 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)

        Q = self.W_q(query).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(key).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(value).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)

        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)

        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))

        attn_weights = F.softmax(scores, dim=-1)
        context = torch.matmul(attn_weights, V)

        context = context.transpose(1, 2).contiguous().view(batch_size, -1, self.d_model)
        return self.W_o(context)


class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        self.register_buffer('pe', pe.unsqueeze(0))

    def forward(self, x):
        return x + self.pe[:, :x.size(1)]


class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()
        self.attention = MultiHeadAttention(d_model, n_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.GELU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout),
        )

    def forward(self, x, mask=None):
        x = self.norm1(x + self.attention(x, x, x, mask))
        x = self.norm2(x + self.ffn(x))
        return x


d_model, n_heads, d_ff = 512, 8, 2048
block = TransformerBlock(d_model, n_heads, d_ff)
x = torch.randn(2, 100, d_model)
out = block(x)
print(f"Input shape: {x.shape}, Output shape: {out.shape}")
```

## 总结

- Transformer 基于自注意力机制，实现了完全并行的序列建模
- 缩放点积注意力通过除以 $\sqrt{d_k}$ 稳定梯度
- 多头注意力允许模型同时关注不同表示子空间
- 位置编码为无递归结构注入序列顺序信息
- 稀疏注意力和线性注意力是降低 $O(n^2)$ 复杂度的重要方向
