## Introduction

Optimization is the engine of machine learning: training models amounts to minimizing loss functions. This note covers the calculus and optimization theory needed to understand why and how learning algorithms work.

## Multivariate Calculus Review

### Gradient

For $f: \mathbb{R}^d \to \mathbb{R}$, the gradient is:

$$\nabla f(\mathbf{x}) = \begin{pmatrix} \frac{\partial f}{\partial x_1} \\ \vdots \\ \frac{\partial f}{\partial x_d} \end{pmatrix}$$

The gradient points in the direction of steepest ascent: $-\nabla f(\mathbf{x})$ is the direction of steepest descent.

### Hessian Matrix

The Hessian is the matrix of second-order partial derivatives:

$$\mathbf{H}_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$$

For twice-differentiable functions, $\mathbf{H}$ is symmetric. The Hessian determines the curvature of $f$:
- $\mathbf{H} \succeq 0$ (positive semidefinite): $f$ is convex
- $\mathbf{H} \succ 0$ (positive definite): $f$ is strictly convex

### Jacobian

For $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$, the Jacobian is:

$$J_{ij} = \frac{\partial f_i}{\partial x_j}$$

The chain rule for compositions: $\mathbf{J}_{\mathbf{f} \circ \mathbf{g}} = \mathbf{J}_{\mathbf{f}} \cdot \mathbf{J}_{\mathbf{g}}$.

## Taylor Expansion

The second-order Taylor expansion around $\mathbf{x}_0$:

$$f(\mathbf{x}) \approx f(\mathbf{x}_0) + \nabla f(\mathbf{x}_0)^\top (\mathbf{x} - \mathbf{x}_0) + \frac{1}{2}(\mathbf{x} - \mathbf{x}_0)^\top \mathbf{H}(\mathbf{x}_0)(\mathbf{x} - \mathbf{x}_0)$$

This approximation underlies Newton's method:

$$\mathbf{x}^{(t+1)} = \mathbf{x}^{(t)} - \mathbf{H}^{-1}\nabla f(\mathbf{x}^{(t)})$$

## Convex Optimization

### Convex Sets and Functions

A set $\mathcal{C}$ is convex if for all $\mathbf{x}, \mathbf{y} \in \mathcal{C}$ and $\theta \in [0,1]$:

$$\theta \mathbf{x} + (1-\theta)\mathbf{y} \in \mathcal{C}$$

A function $f$ is convex if for all $\mathbf{x}, \mathbf{y}$ and $\theta \in [0,1]$:

$$f(\theta \mathbf{x} + (1-\theta)\mathbf{y}) \leq \theta f(\mathbf{x}) + (1-\theta)f(\mathbf{y})$$

### Key Properties of Convex Optimization

1. **Every local minimum is a global minimum**
2. **First-order condition**: $f$ is convex iff $f(\mathbf{y}) \geq f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y} - \mathbf{x})$
3. **Second-order condition**: $f$ is convex iff $\mathbf{H}(\mathbf{x}) \succeq 0$ for all $\mathbf{x}$

## Constrained Optimization

### Lagrange Multipliers

For $\min f(\mathbf{x})$ subject to $g_i(\mathbf{x}) = 0$, form the Lagrangian:

$$\mathcal{L}(\mathbf{x}, \boldsymbol{\lambda}) = f(\mathbf{x}) + \sum_{i} \lambda_i g_i(\mathbf{x})$$

Necessary conditions: $\nabla_{\mathbf{x}} \mathcal{L} = 0$ and $g_i(\mathbf{x}) = 0$.

### KKT Conditions

For $\min f(\mathbf{x})$ subject to $h_i(\mathbf{x}) \leq 0$ and $g_j(\mathbf{x}) = 0$:

1. **Stationarity**: $\nabla f + \sum_i \mu_i \nabla h_i + \sum_j \lambda_j \nabla g_j = 0$
2. **Primal feasibility**: $h_i(\mathbf{x}) \leq 0$, $g_j(\mathbf{x}) = 0$
3. **Dual feasibility**: $\mu_i \geq 0$
4. **Complementary slackness**: $\mu_i h_i(\mathbf{x}) = 0$

## Python Implementation

```python
import numpy as np
from scipy.optimize import minimize

# Rosenbrock function (non-convex benchmark)
def rosenbrock(x):
    return (1 - x[0])**2 + 100 * (x[1] - x[0]**2)**2

def rosenbrock_grad(x):
    dx = -2*(1-x[0]) - 400*x[0]*(x[1] - x[0]**2)
    dy = 200*(x[1] - x[0]**2)
    return np.array([dx, dy])

def rosenbrock_hess(x):
    h11 = 2 - 400*x[1] + 1200*x[0]**2
    h12 = -400*x[0]
    h22 = 200
    return np.array([[h11, h12], [h12, h22]])

# Compare optimization methods
x0 = np.array([-1.0, 1.0])
methods = ['Nelder-Mead', 'BFGS', 'Newton-CG']

for method in methods:
    if method == 'Newton-CG':
        result = minimize(rosenbrock, x0, method=method,
                         jac=rosenbrock_grad, hess=rosenbrock_hess)
    elif method == 'BFGS':
        result = minimize(rosenbrock, x0, method=method, jac=rosenbrock_grad)
    else:
        result = minimize(rosenbrock, x0, method=method)
    print(f"{method}: x={result.x}, f={result.fun:.10f}, "
          f"iters={result.nit}")

# Constrained optimization: minimize x^2 + y^2 s.t. x + y >= 1
from scipy.optimize import minimize

def objective(x):
    return x[0]**2 + x[1]**2

constraints = {'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 1}
result = minimize(objective, [0, 0], constraints=constraints)
print(f"\nConstrained: x={result.x}, f={result.fun:.4f}")
print(f"Expected: x=[0.5, 0.5], f=0.5")
```

## Summary

- Gradients and Hessians characterize function behavior for optimization
- Convex functions guarantee global optimality of local minima
- Lagrange multipliers and KKT conditions handle constrained problems
- Newton's method uses second-order information for faster convergence
- Most ML loss functions are non-convex, requiring careful optimization
